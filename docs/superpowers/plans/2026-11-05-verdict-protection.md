# 판정어와 검증 대상 결속 (#129)

목표: 숫자가 없는 `PASS`·`FAIL`·`통과`·`실패`의 변경, 추가, 대상 바꿔치기를 사실 검증에서 차단한다. #108은 변경하지 않는다. 별도 Task/브랜치에서 구현하고, 머지와 운영 코드 갱신은 사용자 승인까지 실행하지 않는다.

## 구현 계약

- 기존 T 건수 fact와 겹치지 않는 판정어를 `T/test_verdict`로 수집한다. `PASSWORD`·`FAILURE` 같은 식별자, 정확한 `fail-closed` 용어와 `통과율`·`실패율` 명사는 제외한다. 한국어 활용형·부정은 의미를 추측하지 않고 원문 진술 전체로 보호한다.
- 원문 판정행은 fact 표기를 ID로 바꾼 비교본으로 고정한다. 허용된 fact 표면 정규화는 기존 검증을 따르고, 그 밖의 대상·조건·부정·부모 문맥·fact 순서 변경은 거부한다. 전체 불릿의 밑줄 표시는 허용한다.
- 판정행의 다른 fact가 남으면 판정어만 제거할 수 없다. 원천 레코드 전체를 선택하지 않는 동작은 유지한다. 모든 근거 ID를 제거한 자연어 재서술의 의미 추적은 보장하지 않는다.
- 원문 판정어를 소유하지 못하는 과거 catalog는 재생성이 필요하다. 판정어가 없는 과거 catalog는 유지한다. 게시 전에도 봉인된 원문·catalog·draft로 새 검증을 실행하며 override로 우회하지 못하게 한다.
- freeform에서는 원문 문맥을 정확히 비교한다. source-selection은 원문에서 재구성한 records와 검증된 selection을 코드로 렌더한 비교본만 허용한다. 테마 이름이나 generationMethod만으로 예외를 만들지 않는다.
- HTML/호환문자/보이지 않는 문자로 숨긴 출력 판정어는 거부용 비교본에서도 검출한다. 이 손실 정규화를 긍정 근거로 사용하지 않는다.
